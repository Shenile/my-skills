# Slop catalog

Read when reviewing or when the first pass looks "fine." Individual items are not sins. Clustered, they are the average.

Any **four** together = fail. One used on purpose, named in the brief, may stand.

## Modes (do not flee into these)

Generated UI clusters. Avoiding purple by landing here is still slop.

1. Purple/indigo/violet gradients, Inter/Geist, glass, glow (classic).
2. Warm cream (~`#F4F1EA`) + high-contrast serif display + terracotta.
3. Near-black + one acid green or vermilion.
4. Broadsheet: hairline rules, zero radius, dense columns, as a costume.

## Palette

Purple / indigo / violet gradients. Cyan-on-dark. Neon with no hierarchy. Cream/beige as the "tasteful" default. Gradient text. Radial glows, aurora blobs, glow `box-shadow`. Repeating-gradient stripes as wallpaper.

## Type

Inter, Geist, Space Grotesk, Instrument Serif as the whole voice. One family at one weight for headings, body, labels, buttons. Italic serif hero. All-caps body. Tracked uppercase kicker / eyebrow / pill chip above the H1. Tiny numbered labels (`01` `02`) that are not a real sequence.

## Layout

Centered SaaS hero: badge, huge sentence-headline, two CTAs, logo row. Identical icon-tile feature cards (rounded-square icon stacked over heading + blurb). Hero metrics: big number, tiny label, three stats. Nested cards. Thick colored left border on cards. Hairline border plus wide soft shadow. Extreme radius (24px+ on a small card). Same 16px gap on every node. Cards flush to the scroller with no gutter.

## Chrome

Glassmorphism with no layering problem. Emoji as nav, bullets, or icons. Status dots (or pulsing dots) that map to nothing. Sparkle / wand / "AI" badge as decoration. Lucide tiles in a 3-column grid. Fake terminal caret. Logo marquee. Bounce/elastic on chrome. Image scale/rotate on hover as the only interaction.

## Copy (on screens)

Streamline, empower, supercharge, world-class, seamlessly, next-generation. Em-dash cadence. Label + sublabel + helper saying the same thing. Aphoristic contrast ("Not X. Y."). Theater framing ("that's theater"). Same string repeated in one card.

## Code tells

`bg-indigo-500` / `from-purple-500 to-blue-600` with no token. `backdrop-blur` on every panel. shadcn defaults unthemed. Decorative CSS grid background. Motion on width/height/padding. Hand-drawn SVG scenes or shape-assembled clip-art as the hero.

## Not this catalog

Contrast ratios, focus rings, heading levels, loading skeletons as craft — out of scope unless they are *decorative* (pulse that fakes liveness, skeleton as a vibe).
